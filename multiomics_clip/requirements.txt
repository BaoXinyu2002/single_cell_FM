# Multi-Omics CLIP Requirements
# This project integrates scFoundation (scRNA-seq) and EpiAgent (scATAC-seq)
# Python version: 3.11 recommended (minimum 3.10 for type hints, EpiAgent tested on 3.11)

# COMPATIBILITY NOTES:
# - PyTorch 2.0.1: Satisfies EpiAgent (>=2.0.0) and scFoundation requirements
# - NumPy <2.0.0: CRITICAL - faiss cannot work with NumPy 2.x (C API breaking changes)
# - flash-attn 2.5.8: Satisfies EpiAgent (>=2.5.7), required for BERT with FlashAttention v2
# - local-attention 1.9.14: CRITICAL - versions >=1.9.15 incompatible with torch 2.0.1
# - transformers 4.27-4.35: Tested compatibility range with torch 2.0.1
# - einops >=0.6.1: Required for torch.compile support in PyTorch 2.0+
# - pybedtools >=0.10.0: Python 3.11+ support requires 0.10.0+
# - CUDA 11.7 recommended for optimal performance with PyTorch 2.0.1 and flash-attn 2.5.8

# Installation Notes:
# IMPORTANT: Follow this exact order to avoid conflicts!
#
# 1. Create Python 3.11 environment:
#    conda create -n sclip python=3.11
#    conda activate sclip
#
# 2. Verify ninja is working (required for flash-attn compilation):
#    ninja --version
#    # If ninja fails or returns nonzero exit code, reinstall:
#    pip uninstall -y ninja && pip install ninja
#
# 3. Install PyTorch first with CUDA 11.7:
#    pip install torch==2.0.1 torchvision==0.15.2 torchaudio==2.0.2 --index-url https://download.pytorch.org/whl/cu117
#
# 4. Install torch-geometric extensions (BEFORE requirements.txt):
#    pip install torch-scatter torch-sparse torch-cluster torch-spline-conv \
#      -f https://data.pyg.org/whl/torch-2.0.1+cu117.html
#    # This installs CUDA-specific compiled wheels for torch-geometric
#
# 5. Install flash-attn (MUST be after PyTorch):
#    pip install flash-attn==2.5.8 --no-build-isolation
#
# 6. Install remaining dependencies:
#    pip install -r requirements.txt
#
# 7. Install EpiAgent package (if not already installed):
#    pip install epiagent
#
# 8. Verify installation (see VALIDATION section at end of file)
